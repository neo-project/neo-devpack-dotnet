# NC2010: range receivers must be byte arrays or strings

Neo contracts support range access for `byte[]` and `string` receivers. A range
on another array type cannot be lowered to the byte-oriented NeoVM operation,
so the compiler reports `NC2010`.

Use an explicitly supported receiver or replace the range with a bounded loop
that copies the required values into a supported collection.

```csharp
// Supported
byte[] payload = values[1..^1];
string text = input[1..^1];

// Reports NC2010
int[] numbers = values[1..^1];
```
