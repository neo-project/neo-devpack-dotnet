# NC4003: floating-point `decimal` and `double` values are unsupported

Neo contracts do not support `System.Decimal` or `System.Double` values. Use an integer or `BigInteger` with an explicit application-defined scale for fixed-point arithmetic.

The analyzer reports this diagnostic for `decimal` and double declarations, parameters, properties, return types, casts, and literals that are classified by the shared decimal usage rule.
